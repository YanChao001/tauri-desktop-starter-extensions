## 推荐阅读路径

- **体验插件**：README → 对应插件 README；遇到安装或运行告警时查排障手册。
- **开发插件**：架构说明 → 开发指南 → 测试规范 → 贡献流程。普通文本命令可以不提供界面；带界面插件先了解通用视图与自定义 HTML 的分工、SDK 与隔离边界。
- **维护市场**：架构说明 → 安全规范 → 发布与管理；跨仓库协议修改先确定可被独立 CI 获取的宿主提交。

## 维护规则

工程文档使用中文、UTF-8 和可读链接。README 保留介绍与最短入口；架构解释运行方式，开发指南解释操作，测试规范说明验证范围，发布指南维护线上操作，安全规范定义审核边界，排障手册按症状连接对应处理。

同一事实只在职责最明确的文档定义，其余使用相对链接。精确工具版本、命令入口、插件权限和构建输出名称链接到配置或源码；跨仓库引用使用宿主仓库链接，使独立检出仍可阅读。新增长期文档加入本索引，不另建 CHANGELOG 或临时排查流水账。

代码、配置和相应文档同步修改。提交前核对命令的工作目录、shell、环境变量及实际实现，检查 Markdown 格式、文件链接和标题锚点。不要把 CI 配置、离线验签或本地成功写成线上已发布、真实桌面已验收；某次变更的实际检查结果留在 PR 和 Release 中。
