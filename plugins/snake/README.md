# 贪吃蛇 / Slither

将 [littensy/slither](https://github.com/littensy/slither) 从 Roblox 移植到隔离 HTML / Canvas 的离线竞技贪吃蛇。围绕自由转向、冲刺、吃食物成长和撞蛇对抗重新实现游戏循环，保留原作的 Catppuccin Mocha 配色、渐变手写标题、皮肤卡片、圆形小地图及游戏音效。固定来源、实际复用资源和完整许可见 [第三方归属与许可](./THIRD_PARTY_NOTICES.md)。

玩家与 12 条本地 AI 在圆形竞技场游玩；游玩、观战和资源加载均离线运行。独立窗口默认 1180 × 820，实际尺寸由 [`extension.json`](./extension.json) 声明，宿主仍记忆用户调整并限制在显示器工作区内。游戏配色独立于宿主主题，界面支持中英文、键盘和触控，字体随包离线内嵌。

## 玩法与操作

- 鼠标指向目标方向，蛇会连续转弯；方向键 / WASD 可组合斜向，松键或手柄摇杆回中后保持最后方向。触控摇杆和冲刺可由两根手指独立操作，按触点分别释放。手柄左摇杆控制方向，A 键 / 扳机控制冲刺；Gamepad API 不可用或被策略拒绝时，键鼠与触控仍可使用。移动始终连续进行，长蛇的转弯速度会随长度增加而降低。
- 按住鼠标左键、空格、Shift 或触控冲刺按钮加速。冲刺消耗长度并沿尾部掉落食物；长度降到初始值后停止加速，放开按钮恢复常速。
- 吃普通食物或其他蛇死亡后留下的食物成长。头部撞到其他蛇的身体或圆形边界会死亡；可以经过自己的身体。头对头相撞时长度较低的一方死亡，同长度时双方死亡。AI 死亡后会重新进入竞技场。
- 菜单可选择三档难度、15 种免费皮肤和最多 24 个 Unicode 字符的昵称，支持完整 emoji，并在输入法提交后更新。昵称以保持水平的标签显示在玩家蛇头旁，空昵称显示“你”；观战目标和其他 AI 也显示名字。难度影响 AI 冲刺频率和避让距离；皮肤只改变视觉，不改变碰撞和长度。每局种子随进度保留，相同种子、难度与输入历史能重现同一局。
- `P` 或暂停按钮暂停，`Esc` 暂停并回菜单，`M` 切换静音。失焦、文档隐藏或宿主操作时暂停，返回后手动继续；恢复时不追赶离开期间的游戏时间。
- 菜单底栏的眼睛图标与“观战”文字进入 AI 观战，可切换观察目标，退出后保留玩家自己的对局。观战暂停后，顶部按钮、面板按钮与 `P` 均继续同一场比赛和目标；虚拟玩家死亡不重置仍在进行的 AI 比赛，完整回合到达上限后才续新场。游戏显示当前长度、最高长度、击败数和排名，圆形小地图标记自己与其他蛇的位置。暂停与结算面板均提供“返回主菜单”，保留本局进度和成绩；结算页只保留一个新局入口。
- 每局按固定 20 Hz 步进，最多 12000 个逻辑步，即 10 分钟有效游戏时间；暂停不计时。死亡或达到回合上限后进入结算，可保存纪录并新开一局。输入日志达到安全上限时暂停并提示新开局，保留本局以供保存或导出。

菜单、皮肤、排行榜、暂停与结算复用同一套游戏视觉。导航、可滚动内容和底栏分别占位，主页署名仅在主页显示，窄屏底栏换行。短窗口的声音面板、暂停、结算和确认面板可滚动，游戏画布按实际尺寸等比绘制；空间不足时收起地图与领先榜，以紧凑长度 / 峰值和控制按钮为主。暂停、结算与确认面板约束键盘焦点，背景控件不可被操作。调整模式或重新开始前先保留已有进度；游戏中的方向、冲刺、音量和皮肤设置不经过宿主页面样式。

## 进度、纪录与权限

[`ui/main.html`](./ui/main.html) 负责即时游戏和输入，[`src/arena.rs`](./src/arena.rs) 在 Wasm 中独立重放规则。检查点只保存 schema、非零种子、难度、皮肤、昵称、音量、静音与压缩的角度 / 冲刺输入历史，不接受预计算的分数、蛇身、食物或 AI 状态。恢复时先重放核验，再以暂停状态继续。日志段数、JSON 字节数、蛇身与食物数量都有上限，精确边界以引擎校验为准。

检查点与会话状态保持 **schema 3**，私有纪录使用 **schema 4**。旧四方向格子蛇的 schema 1 / 2、未知 / 未来版本、损坏数据、超长日志和结束后仍有输入的不可达历史会被拒绝。原始存档保留，不自动迁移到新规则、不删除后重建，也不把旧格子蛇分数写入新排行。不兼容导入需要用户明确新开局后才登记新进度；不受支持的私有纪录保持禁写，离线游玩与会话导出仍可使用。

已知 schema 3 的自由转向纪录经完整校验后，仅在内存中升级为 schema 4；查看、核验或启动游戏不会写入存储，下一次用户主动保存才通过当前 revision CAS 写回。原有八位哈希 ID 无法反推种子，作为历史项原样保留；新局使用非零种子的八位十六进制值与一位难度码组成精确九位 ID，避免不同种子或难度因哈希碰撞被误合并。再次保存旧局时可能同时保留历史项和新身份项，这是保留原纪录的取舍，不推测种子或删除原成绩。旧版待确认保存状态与旧 schema 成功回执不会被猜测升级，仍按完整预期值严格核对；遇到这类旧会话应先恢复已保留的对局检查点、刷新纪录，再决定是否主动保存。

游戏运行期间合并登记宿主 checkpoint，宿主忙碌时延后；进度登记失败时暂停并允许重试。临时对局不作为未保存编辑阻塞导航，长期保留请通过宿主会话工具导出。切页停止等待不表示原生操作已回滚。

插件无必需权限，`storage` 是唯一可选权限。未授权仍能游玩、观战和导出会话；授权后可主动保存纪录。Wasm 从种子重放本局后，按**本局曾达到的最高长度**更新三档难度的最佳成绩及全局 Top 10，避免冲刺后的长度减少使纪录下降。未开始的菜单进度不进入 Top 10；新版纪录中同一种子与难度只保留较高成绩，换皮肤、昵称或音量不产生新的排行项。排行榜是本机纪录，重放核验也不提供真人联网排行榜的身份或防作弊认证。

纪录保存到本插件的 `snake-records` 私有键，采用宿主当前 revision CAS。成功回执必须匹配 effect ID、预期 revision 和完整 schema 4 纪录值后才更新显示；另一窗口改写、保存取消、失败或响应省略时保留当前局，不自动重复写入。取消等待后写入可能已经完成，应刷新纪录再决定下一次保存。纪录不是完整对局备份，游戏进度仍通过宿主 checkpoint / 会话保留；卸载不承诺清除私有存档。

## 视觉、音效与平台边界

界面采用原版 **Catppuccin Mocha** 色板与原始手写 Slither 标题，主按钮、皮肤、HUD、蛇身及食物延续柔和渐变和光晕。Inter 变量字体以原始 WOFF2 离线内嵌，中文由系统字体补齐。资源、界面代码和许可共同受宿主单文档 **512 KiB** 预算约束，不请求远程字体、脚本或页面，也不新增运行依赖。

游戏使用 10 个原版 Ogg 音效，包括开始、进食、冲刺开始 / 停止、三种死亡提示、按钮按下 / 松开与皮肤切换。它们来自原作使用的 Kenney Interface Sounds 素材包，按 CC0 1.0 分发；播放只做音量和速度调整。用户手势解锁声音，菜单底栏的声音入口统一提供静音、音量滑块和百分比；Esc、关闭按钮或点击外部可收起，切页时自动收起。原作主页按钮仅控制背景音乐，音效音量面板是本地移植新增。暂停、隐藏与卸载时挂起或清理音频，音频不可用仍可游玩。减少动效关闭装饰动画，不改变规则与模拟速度。

原作是 Roblox 在线游戏，本地移植保留独立可运行的竞技玩法，以 AI 替代平台服务器中的其他玩家。昵称仅用于本地显示；本插件不连接 Roblox 账号、真人多人服务器、聊天、语音、Robux 支付、商城或平台成就。15 种皮肤离线免费可用，包括 14 种 Mocha 强调色和彩虹，未复制原作付费解锁流程。原版音乐只给出 Roblox 库资源 ID，仓库没有可独立分发的音乐文件，本插件不分发这些曲目。原项目与素材作者的署名和独立许可随包保留。

## 适配取舍与影响

此次移植同时改变玩法、恢复契约与纪录含义。原四方向棋盘、穿墙和固定障碍由连续运动的圆形竞技场替代；保留宿主的隔离 UI、生命周期和消息桥，游戏不访问宿主 DOM 或直接调用原生 IPC。独立窗口尺寸和游戏样式通过现有宿主能力声明，无新增网络、文件或原生服务权限。命令使用宿主 0.1.7 起提供的 `compute` 运算档位，为完整对局的 Wasm 重放提供有界燃料预算；仍受宿主的墙钟超时、取消与内存限制约束，其他插件的默认额度不变。当前包最低要求宿主 0.1.8，配套共享界面规则见[发布指南](../../docs/publishing.md#固定配套宿主)。

原作的 20 Hz 节拍和长度驱动增长 / 转向规则继续使用；Roblox 的浮点向量、蛇段插值、服务端广播与平台随机数改为浏览器和 Rust 共用的整数规则、固定轨迹点与有种子随机数。360°方向输入在模拟中量化为 256 个角度，约 1.4°一档，并按转向速度平滑追踪。浏览器负责绘制，Wasm 独立校验整局，避免跨运行时浮点差异让恢复或保存失配。

为限制单文件资源、主线程负载和 Wasm 重放成本，本地竞技场采用 12 条 AI，替代上游至少 25 条蛇；初始普通食物 540 颗、全部食物最多 700 颗，蛇身最多 160 个轨迹点。AI 保留寻食、避边界、避蛇与冲刺，并提供三档难度；死亡掉落使用有界近似。这些容量和回合上限属于本地适配取舍，未承诺与 Roblox 服务器逐帧一致。旧版无法表达连续方向与 AI，因此使用 schema 3 并保留旧原件拒写。

验证重点是浏览器与 Rust 的同种子世界摘要一致、非轴向转弯、冲刺消耗、成长、撞击、掉落、AI 重生、10 分钟回合边界、非法历史，以及 checkpoint / CAS 失败后数据保留。主菜单、皮肤、观战、暂停、结算、排行榜、中英文、窄屏触控、焦点和无障碍通过无头浏览器检查。真实桌面窗口尺寸、WebView 音频策略与平台生命周期需要在隔离环境或安排的前台时段验收，本地自动检查不代表这些范围已通过。

## 构建与验收

先按 [开发指南](../../docs/development.md#准备宿主校验工具) 准备宿主 `extension-tool`。从**市场仓库根目录**验证规则、界面回归并构建 Wasm：

```sh
cargo test --locked --manifest-path plugins/snake/Cargo.toml --target-dir target/snake-native
node --test plugins/snake/ui/arena.test.mjs plugins/snake/ui/main.test.mjs
cargo build --locked --release --target wasm32-unknown-unknown --manifest-path plugins/snake/Cargo.toml --target-dir target/snake
```

从**宿主仓库根目录**对真实模块与 HTML 快照执行 fixture：

```sh
pnpm extension:test --manifest marketplace/plugins/snake/extension.json --wasm marketplace/target/snake/wasm32-unknown-unknown/release/market_snake.wasm --ui-dir marketplace/plugins/snake/ui --fixture marketplace/plugins/snake/smoke.json
pnpm extension:test --manifest marketplace/plugins/snake/extension.json --wasm marketplace/target/snake/wasm32-unknown-unknown/release/market_snake.wasm --ui-dir marketplace/plugins/snake/ui --fixture marketplace/plugins/snake/smoke-records.json
```

[`smoke.json`](./smoke.json) 覆盖双语启动、非轴向输入重放、分数核验、存储请求及成功 / 冲突 / 取消 / 响应省略回执；[`smoke-records.json`](./smoke-records.json) 覆盖已知纪录升级、哈希碰撞种子的独立保存、精确身份重复保存和非法身份 / 旧回执拒绝。原生测试覆盖数据版本、边界校验、峰值纪录与 CAS；界面回归覆盖输入、检查点合并、恢复和保存。完整市场检查、包验证与分层边界见 [测试规范](../../docs/testing.md)。
