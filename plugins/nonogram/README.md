# 数织画室

独立 Rust / Extism 插件，使用包格式 3、API 2 与视图版本 2。包含爱心、小树与钻石三个 5×5 数织谜题；规则测试会枚举满足行线索的所有排列，并逐一对照列线索，确保每题恰好一个解。

棋盘左侧为行线索，上方为列线索。连续数字表示填充块的长度，多段之间至少留一格空白。选择“填充”或“标为空白”后点击格子；相同工具重复点击会清除标记。支持撤销、重置、检查答案和揭示一格。提示会先修正错误标记，再揭示未知格，明确属于答案提示，不冒充纯逻辑推导。完成校验不强制为空白格全部打叉。

不需要必需权限，也不请求网络、文本或文件能力。可选 `storage` 在用户点击保存时通过真实宿主效果保留当前题目、工具及操作历史；恢复会先校验存储状态。写入检查 revision，冲突时保留当前棋盘，提示用户核对后手动操作。切换题目会开启该题新棋盘，离开前可先保存或通过宿主导出会话。

插件只接受 schema 1 的有界操作历史，最多 1024 次标记；重放时检查坐标、标记值与无效重复操作，不接受直接传入答案棋盘。未知 schema、额外字段、超大或非法历史均被拒绝。没有保存进度或保存内容损坏时保持当前棋盘，不删除数据。

从市场仓库根目录验证规则：

```sh
cargo test --manifest-path plugins/nonogram/Cargo.toml --locked --target-dir target/nonogram-native
```

市场统一构建流程会编译 Wasm，并通过宿主真实 worker 执行 [手写 smoke fixture](./smoke.json)，覆盖中英初始化、标记、提示、撤销、错误校验、保存请求、回执及恢复；宿主完整校验每份返回视图。规则单测同时验证唯一解、提示正确性、标记与撤销、完成语义和存储 CAS。
