# 壁纸库

四个免费壁纸站、本机图库与应用背景管理，支持真实关键词搜索、分类浏览、长页续接、分页去重和高清预览。插件 Wasm 负责站点 URL、公开列表 HTML / JSON 解析、图片身份与有界会话，自定义 HTML 负责平铺预览与交互；配套原生宿主提供通用 HTTP、图片资源、外链、图库和共享界面规则。版本与最低宿主要求见 [清单](./extension.json)，配套发布见 [发布指南](../../docs/publishing.md#固定配套宿主)。

## 功能与授权

页面留白和普通图片卡片跟随宿主皮肤强度；输入、下拉菜单、图片预览和确认弹窗保留阅读底色，规则见 [宿主 SDK](https://github.com/YanChao001/tauri-desktop-starter/blob/develop/sdk/README.md#默认外观与动效)。

`wallpapers:manage` 是本机图库的必需权限，允许列出、通过用户对话框导入、重命名、移除图片、设置应用背景及打开图库设置。这里设置的是应用背景，不是操作系统桌面壁纸。拒绝所有可选网络权限时，本机功能仍可使用。

其他能力分别可选授权：

| 权限                   | 用途                                                                                    |
| ---------------------- | --------------------------------------------------------------------------------------- |
| `network:https`        | Wasm 通过 HTTP effect 读取清单声明的四个壁纸站的公开 HTTPS 列表                         |
| `network:images`       | 通过通用资源服务下载公网 HTTPS 缩略图或原图，预览、另存及加入图库                       |
| `links:open`           | 用户点击后，在外部浏览器打开图片来源页，核对来源与使用许可                              |
| `network:system-proxy` | 宿主选择系统代理时允许上述已获授权的网络请求使用代理；不额外授予图源 API 或图片网络权限 |

界面按具体授权启用入口并说明限制。仅授予系统代理不能加载或下载图片；连接方式统一继承宿主“设置 → 网络”的选项，插件不再提供局部选择，也不在检查点保存或恢复连接偏好。关闭权限不会以空结果或保存成功冒充操作已完成。

## 图源、预览与资源

通过下拉列表切换图源，每个站点页最多 24 张不同图片。向下接近页尾时自动读取下一页并追加，保留已有图片和滚动位置；页尾也提供手动加载与失败重试。每次只请求一个真实列表页，不以连续随机请求凑满数量，不自动预取整个站点。最多浏览 40 页、累计至多 960 个图片身份，不会回绕第一页。续接过滤已经显示的身份，遇到空页、全为已看图片或站点末页时结束。重新搜索、换源或分类从第一页重新浏览；输入关键词本身不发请求，点击搜索或按 Enter 后才提交。失败保留已有长页和实际筛选，页尾重试当前未成功页；恢复会话恢复最近一页，完整长页只保留在当前打开的界面中。

关键词搜索使用全站范围，分类归一为“全部”；关键词非空时先清空搜索框才能切换分类，分类浏览从第一页开始，避免把站点不支持的组合标成已生效。关键词会发送至所选站点。壁纸汇与猫猫壁纸酷支持中文检索，壁纸汇无匹配时的无关推荐会被过滤；其他两个来源建议使用英文关键词。切换语言与恢复已有结果不会重发请求；图库与网络权限分别授权。

| 图源            | 站点                                     | 请求与图片身份                                                                                                                                                                                                         |
| --------------- | ---------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 壁纸汇          | [免费壁纸](https://www.bizhihui.com/)    | 首页、分类与 `search.php?q=` 搜索；缩略图与原文件绑定 `s.panlai.com` 同一路径，移除站点的缩略后缀获取文件；来源保留实际详情页。                                                                                        |
| 猫猫壁纸酷      | [壁纸目录](https://www.wallcoo.com/)     | 使用站点公开 `/wp-json/bc/v1/wallpapers` 目录的真实搜索、分类与页码；缩略图与 `largeUrl` 绑定同一文件。保存公开高清适配文件，不保存 600 秒临时原图地址，不把目录中的原图尺寸冒充适配文件尺寸；完整原图通过来源页下载。 |
| WallpapersCraft | [桌面壁纸](https://wallpaperscraft.com/) | 最新、分类与 `/search/?query=`；限定 1920×1080 文件，缩略图和下载图绑定同一图片名称与编号。                                                                                                                            |
| GoodFon         | [免费桌面壁纸](https://www.goodfon.com/) | 最新、分类与 `/search/?q=`；从列表读取实际尺寸，缩略图与原文件绑定相同路径、图片名及来源详情页。                                                                                                                       |

来源包含公开网页适配和站点公开 JSON 目录，均不代表站点承诺长期保持接口不变；仅按用户操作读取有界列表，不批量抓取全站，也不绕过登录、验证码或付费下载。GoodFon 页脚标注 2008 年起、WallpapersCraft 标注 2013 年起，猫猫壁纸酷自述为近三十年的老品牌恢复运营；壁纸汇较新，四站可访问性仍取决于网络与站点维护。网页结构变化、反爬、限流或网络异常会明确报错，保留上次成功列表及其实际筛选，不用旧结果冒充新筛选成功。

免费下载不代表图片可任意使用。许可由原作与各站点页面决定，使用前通过“来源”核对归属、站点条款与许可；插件不把图源标签解释为版权授权。WallpapersCraft 下载文件为 1920×1080 版本，猫猫壁纸酷保存其公开高清适配文件，界面使用“保存高清图”，不把它们标成站点最高分辨率原图。

撤销 HTTPS 权限后，在途结果不会替换已经显示的列表；重新授权后，通过新的查询或刷新加载结果。图库预览处理繁忙时保留已有列表并提示重试，不把暂时繁忙标记为图片损坏。

切换本机图库先取得可操作的元数据卡片，再按封面摘要逐张读取缩略图；已有成功列表和预览可复用，首次不等待整库缩略图生成。后台读取只标记图库更新状态，不禁用整个插件。在线搜索、图片下载与图库读取相互独立，慢图源不阻止本机操作。应用背景、导入、重命名与移除期间仍防止重复写入；在途旧读取不能覆盖新操作的结果，旧封面预览不能覆盖新封面。

应用背景使用独立进度，只在正在切换的图片上显示“正在设置”；保存期间仍可切页、搜索、刷新图库和打开设置，同时限制重复图库写入。从插件 1.4.0 / 宿主 0.1.10 起，设置只接收轻量保存回执，在已有图库上更新当前项和 revision，保留名称、容量和缩略图；不等待或自动重新读取图库，预览和旧读取失败不会把已确认保存改报失败。当前使用项只在原生确认后更新，晚到的旧回执不会回退已读取的更新状态。完整接口见 [宿主壁纸服务契约](https://github.com/YanChao001/tauri-desktop-starter/blob/develop/docs/extensions.md#壁纸图库与图片搜索)。

请求经 HTTP effect / `host-result` 完成；插件验证图源、关键词 / 分类、页码、effect ID、URL、状态与有界 HTML / JSON，再原子替换列表和成功筛选。会话 schema 4 只保存经验证的有界元数据、分页状态和已见图片身份，不保存图片二进制、系统路径或原生资源 ID；旧搜索会话与未来状态拒绝覆盖并保留原件。结果标识不代表下载资格。

图片卡片通过通用资源服务获取并重绘为安全 data URL，不直接加载远程 `img`。宿主 0.1.11 的合并下载 / 预览在一次解码中返回安全图片，避免逐张 Fetch / Preview 的重复解码；已收到的图片先显示，原生句柄另行有界释放。图片按可见区域优先加载，长页未滚到的图片保留占位。缩略图内存缓存有界，不写入会话；图片撤权、访问失效或卸载时清空，晚到结果不能重新填充。资源绑定当前安装和窗口并有有效期，失效后重新获取；成功、失败、取消、卸载和切换后的晚到回调均清理句柄，不带入会话。初始化、前台操作、图片和状态保存统一限制消息桥并发，避免首次打开争抢四项请求容量；本机繁忙与站点返回错误分别提示。

大图先显示已有缩略图，再通过 `fetch-image` 的 `preview: "large"` 单独获取站点提供的高清适配图：最长边最多 2560 像素，安全 JPEG data URL 最多 256 KiB。壁纸汇使用实际详情图 `-arthumbs`，GoodFon 使用 `/wallpaper/nbig/`，WallpapersCraft 使用 1920×1080 文件，猫猫壁纸酷使用目录明确给出的 `largeUrl`。适配图的实际尺寸可能小于原文件，宿主不会将小图放大编码。卡片仍使用最多 320 像素、24 KiB 的轻量缩略图；两个后台缩略图之外为所选高清图保留独立加载空间，关闭或切换时取消旧高清下载，成功大图使用有界内存缓存，再次打开无需重复下载。高清失败保留占位图并可重试，快速切换、关闭、撤权后的晚到结果不能覆盖当前图片。预览提供前后切换和方向键，顶部信息图标查看尺寸与来源，Esc 按层关闭并恢复焦点。

- **保存高清图**：资源服务核验 MIME、真实解码与额度，再通过原生另存对话框保存已验证文件。已知源尺寸超过每边 8192 像素或 1600 万像素时使用站点高清适配图，并在信息中提示完整尺寸可前往来源获取；取消明确返回取消，不暴露系统路径。
- **加入图库**：获取高清适配图并把有效图片资源交给图库 `import-resource`；宿主重绘压缩并核验容量，避免为应用背景下载超大原图。界面按响应中的 `limit` 显示容量，无效或超额列表会被拒绝并保留已加载内容；压缩副本不作为原始文件另存。
- **应用背景**：选择图库图片及覆盖 / 完整显示方式，使用既有设置 revision CAS 保存并同步多窗口；冲突时刷新后重新选择。
- **本机管理**：本地图片通过用户选择导入；点击缩略图设为应用背景，右上角勾选表示当前使用项，名称旁的铅笔与垃圾桶图标直接重命名或移除。移除前确认；移除当前使用项后恢复纯色背景，不删除用户原始文件。其他窗口已经修改背景设置时，旧快照的移除操作会提示冲突并保留图片，刷新后再操作。

原图最多 16 MiB、每边 8192 像素、总计 1600 万像素。上游可能提供超过额度的高分辨率原图，此时预览仍可使用较小缩略图，下载与导入按宿主实际反馈处理。公网 URL、MIME、真实解码与额度最终由 [原生安全边界](../../docs/security.md#原生服务与外部来源) 核验；不跟随重定向或放宽 TLS。

## 网络连接

在宿主“设置 → 网络”中选择直接连接或跟随系统代理，默认跟随系统代理。壁纸库的图源 HTTP effect 与 `fetch-image` 均省略 `networkMode`，随请求继承宿主设置，不恢复旧检查点中的模式。直接连接禁止代理，宿主核验全部解析地址并固定到本次连接，拒绝私网、环回及保留网段。VPN Fake-IP 等合成保留地址可能因此被拒绝。

系统代理仍需要给壁纸库独立授予 `network:system-proxy`；宿主选择系统代理但插件未获授权时回落直连。代理沿用宿主支持的用户系统配置和排除规则，插件不能指定代理 URL、任意请求头、关闭 TLS 或绕过来源声明。命中系统代理时，宿主不能核验代理远端最终解析的目标 IP；没有匹配代理或被排除而直连时仍执行 DNS 检查。授权系统代理表示接受该信任边界，不承诺任意 PAC 支持；显式旧 `networkMode` 的兼容与权限规则见 [宿主扩展指南](https://github.com/YanChao001/tauri-desktop-starter/blob/develop/docs/extensions.md#来源与授权)。

## 开发与验证

从市场仓库根目录运行：

```sh
cargo test --locked --manifest-path plugins/wallpaper-browser/Cargo.toml --target-dir target/wallpaper-browser-native
cargo clippy --locked --manifest-path plugins/wallpaper-browser/Cargo.toml --target-dir target/wallpaper-browser-native --all-targets -- -D warnings
cargo build --locked --release --target wasm32-unknown-unknown --manifest-path plugins/wallpaper-browser/Cargo.toml --target-dir target/wallpaper-browser
node --test plugins/wallpaper-browser/ui/main.test.mjs
```

依赖用途与版本见 [Cargo.toml](./Cargo.toml) 和 [Cargo.lock](./Cargo.lock)：`serde` / `serde_json` 处理状态与响应，`url` 负责 URL 规范化。它们均为 MIT / Apache-2.0 许可的纯 Rust 依赖，支持原生测试和 Wasm，不新增系统库或网络运行时；包体以实际构建产物为准。

原生测试检查四站 HTML 解析、关键词编码与长度、真实分类、固定图片身份、跨批去重、分页结束、零 / 少量结果、失败保留筛选与 HTTPS 来源；手写 [`smoke.json`](./smoke.json) 检查真实 Wasm 图源 effect、回执和授权。UI 回归检查高清请求、切换与晚到结果隔离、重试和资源释放。迭代时按 [改动范围](../../docs/testing.md#按改动选择检查) 选择检查，交付完整产物前运行市场 `check`。资源、网络、图库 CAS、真实网站、WebView 与对话框的分层验收见 [测试规范](../../docs/testing.md#固定原生服务验收)，DOM / SDK 替身不代表真实联网成功。

既有图库、背景偏好和设置保留；不以清空图库修复图源错误。会话文件绑定插件及 UI 文档版本，旧会话不能冒充新版状态，配套发布见 [发布指南](../../docs/publishing.md#固定配套宿主)。
