# 壁纸库

可操作的必应图片搜索与本机图库。自定义 HTML 提供关键词搜索、来源说明、预览和图库管理，Wasm 仅初始化受验证的视图，实际系统操作通过 `starter.services.request("wallpaper", request)` 完成。

## 功能与授权

浏览与管理共用必需权限 `wallpapers:manage`。安装审阅时确认用途、授予该权限并启用，即可列出和导入本机图片、搜索必应图片、访问结果中的第三方 HTTPS 图片来源、下载原图、重命名、移除、设置应用背景，并打开“图库设置”。界面中的缺少授权提示用于旧会话或授权变化时的防御处理。图片只通过原生对话框导入或另存，插件不能提供系统路径。这里的背景是应用背景，不是操作系统桌面壁纸。

关键词原文发送至固定的 `https://cn.bing.com/images/search`，原生解析时核对搜索框及结果链接的关键词与请求一致，预览使用必应缩略图，下载使用结果中的第三方 HTTPS 原图。搜索不自动发起；只有用户搜索或选择预览、导入、下载时才访问网络。**不按 Public domain / CC0 或其他许可筛选，也不保证图片的使用许可**；界面保留标题、来源页和尺寸信息。当前使用网页解析，遇到验证码、网页改版或限流可能失败，不把它描述为稳定的官方搜索 API。

宿主为搜索结果生成不透明 `resultId`，在有界、带 TTL 的内存缓存中绑定插件安装身份与原生窗口。界面只提交该标识，不能提供下载 URL；过期、重启或身份变化后需重新搜索，其他窗口不能复用。旧会话的 Commons `pageId` 操作继续兼容原有固定来源和 Public domain / CC0 复核，不参与新版默认搜索。

- **下载原图**：验证 MIME、真实解码和尺寸后，通过原生另存对话框保存原始文件，最多 16 MiB、8192 像素每边、1600 万像素。取消保存会明确返回取消。
- **加入图库**：下载搜索结果的原图，原生重绘并压缩为现有图库支持的 JPEG；受当前图库 24 张及每张数据额度限制。旧 Commons 兼容操作沿用服务端预览图。图库中的压缩副本不作为原始文件另存。
- **应用背景**：选择图库图片与覆盖 / 完整显示方式，使用设置 revision CAS 保存并同步多窗口；冲突时刷新后重新选择。
- **本机管理**：本地图库在断网时仍可使用。移除当前应用背景前要求用户确认，同时恢复纯色背景。

远程图片不会作为 iframe 的远程 `img` 加载；宿主只返回小型重绘 data URL。必应缩略图限制到图片服务来源，原图必须来自当前有效搜索结果；全部请求保留 HTTPS、SSRF / DNS、正常 TLS、禁止重定向、MIME、真实解码和资源额度校验，只接受 JPEG、PNG、WebP。HTTP 原图、需登录或 Cookie 的来源、跳转、超限与其他格式会明确拒绝。

## 网络连接

默认“跟随系统代理”，沿用锁定 reqwest 版本支持的系统配置及 `HTTP_PROXY` / `HTTPS_PROXY` / `ALL_PROXY`、`NO_PROXY` 环境规则；没有配置匹配代理或被排除时直接连接。插件只能选择跟随系统或直接连接，不能自行指定代理地址、请求头、目标域名或关闭证书检查。用户代理可能为本机服务，这由系统网络设置决定，不代表插件获得任意本机网络权限。

每次请求使用绑定该次目标域名的独立网络客户端，URL 拒绝 IP 字面量和保留域名。实际直连时，受限 resolver 核验目标的全部 DNS 地址均为公网，并将同一组已验证地址交给连接器，拒绝私网、环回和 Fake-IP；跟随系统但未匹配代理或命中排除规则时也执行同样检查。系统选出的代理传输主机自身可以位于本机 / 内网；通过代理解析远端目标时，宿主不会得到目标的本地 DNS 解析结果，也无法核验代理最终连接的 IP，不声称代理路径具有与直连相同的最终地址保证。HTTPS、正常 TLS、来源结果绑定、禁跳转和图片额度仍须生效；普通插件 HTTP broker 不受此服务策略影响。

“直接连接”明确禁用代理。若 VPN 将必应或图片原站解析为 `198.18.0.0/15` 等 Fake-IP / 保留网段，直连会拒绝；可为相应域名配置真实公网 DNS，或使用已正确配置且由代理解析目标的系统代理，并接受上述最终 IP 不可见的边界。系统代理与排除规则由当前平台及 reqwest 实际支持情况决定，不承诺执行任意 PAC 脚本。旧 Commons 兼容路径的固定来源代理策略仍由配套宿主实现维护。

## 开发与验证

```sh
cargo test --manifest-path plugins/wallpaper-browser/Cargo.toml --locked
```

在市场仓库根目录按[开发指南](../../docs/development.md)设置配套宿主工具，运行完整市场构建。`smoke.json` 验收真实 Wasm 初始化且无隐式副作用；解析、结果标识隔离 / 过期、来源、入参、尺寸、重绘、设置和图库连接由宿主隔离单元测试验证。测试不修改用户壁纸、真实图库或设备设置。真实必应搜索、第三方原图连通性、原生对话框和 WebView 交互需单独验收。

此搜索变更必须重新构建并重启配套原生宿主，再重建插件包；仅刷新前端不能给旧 Rust 进程添加能力。缓存不落盘，本次不迁移图库、设置或扩展存档。完整契约与决策见[宿主扩展指南](https://github.com/YanChao001/tauri-desktop-starter/blob/develop/docs/extensions.md#壁纸图库与图片搜索)和[必应搜索 ADR](https://github.com/YanChao001/tauri-desktop-starter/blob/develop/docs/adr/0014-bing-image-search.md)。
