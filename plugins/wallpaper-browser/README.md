# 壁纸库

四个免费 API 图源、本机图库与应用背景管理。插件 Wasm 负责图源 URL、JSON 解析、去重和有界会话，自定义 HTML 负责平铺预览与交互；宿主提供通用 HTTP、图片资源、外链和已有图库能力。1.2.4 使用关键词、分类与主题筛选会话，需要配套 **0.1.8 原生宿主**提供共享界面规则与原生服务，并更新插件包；宿主图片请求带固定应用标识以满足图源识别要求。

## 功能与授权

页面留白和普通图片卡片跟随宿主皮肤强度；输入、下拉菜单、图片预览和确认弹窗保留阅读底色，规则见 [宿主 SDK](https://github.com/YanChao001/tauri-desktop-starter/blob/develop/sdk/README.md#默认外观与动效)。

`wallpapers:manage` 是本机图库的必需权限，允许列出、通过用户对话框导入、重命名、移除图片、设置应用背景及打开图库设置。这里设置的是应用背景，不是操作系统桌面壁纸。拒绝所有可选网络权限时，本机功能仍可使用。

其他能力分别可选授权：

| 权限                   | 用途                                                                                    |
| ---------------------- | --------------------------------------------------------------------------------------- |
| `network:https`        | Wasm 通过 HTTP effect 访问清单声明的四个公共 HTTPS GET 图片 API                         |
| `network:images`       | 通过通用资源服务下载公网 HTTPS 缩略图或原图，预览、另存及加入图库                       |
| `links:open`           | 用户点击后，在外部浏览器打开图片来源页，核对来源与使用许可                              |
| `network:system-proxy` | 宿主选择系统代理时允许上述已获授权的网络请求使用代理；不额外授予图源 API 或图片网络权限 |

界面按具体授权启用入口并说明限制。仅授予系统代理不能加载或下载图片；连接方式统一继承宿主“设置 → 网络”的选项，插件不再提供局部选择，也不在检查点保存或恢复连接偏好。关闭权限不会以空结果或保存成功冒充操作已完成。

## 图源、预览与资源

通过下拉列表切换图源，每批平铺最多 24 张不同图片。输入关键词不会发起请求，点击搜索或按 Enter 才提交；切换图源清空关键词并恢复其默认分类，选择分类 / 主题会加载对应结果。关键词会发送至所选服务。切换语言与恢复已有结果不会重发请求；图库与 API 权限分别授权，不使用必应搜索。

| 图源              | 官方接口说明                                                           | 请求与图片身份                                                                                                                                                                                                                                                  |
| ----------------- | ---------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| UPX8              | [免费壁纸 API](https://wp.upx8.com/)                                   | 支持官方 10 个分类与 content 关键词。关键词非空时按官方规则优先，分类归一为全部，避免误称同时筛选。全部随机时跨分类汇聚、去重并有界补齐 24 张；明确分类 / 关键词仅接收其真实结果。只接受 birdpaper，拒绝 Bing 每日兜底；已知图片 CDN 的 HTTP 地址只升级为 HTTPS |
| Wallhaven         | [官方 API](https://wallhaven.cc/help/api)                              | 支持 q 关键词和综合 / 动漫 / 人物分类组合，固定 SFW；空关键词随机排列，非空按相关性排列，刷新翻页。原图与缩略图绑定同一壁纸 ID                                                                                                                                  |
| Wikimedia Commons | [MediaWiki Imageinfo](https://www.mediawiki.org/wiki/API:Imageinfo)    | 支持真实全文搜索及风景 / 山川 / 海洋 / 森林 / 城市 / 太空主题。主题是加入检索的关键词预设，不冒充站点分类；从至多 50 条中接收 JPEG / PNG / WebP，最多 24 张，预览与原图绑定同一文件                                                                             |
| Nekos.best        | [官方 API](https://docs.nekos.best/getting-started/api-endpoints.html) | 支持 neko / kitsune / waifu / husbando 四类；关键词非空调用官方作者 / 作品元数据 search，属于宽松相关检索，不保证字面包含。随机分类两次最多 20 张去重并有界补齐；保留作者、原作页与固定 PNG 地址，剔除已知超额尺寸                                              |

免费接口不代表图片可任意使用。许可由原作与各站点页面决定，使用前通过“来源”核对归属与许可；插件不把 SFW 或图源标签解释为版权授权。UPX8 与 Nekos.best 的随机池可能跨批重复，刷新不保证全站无重复。搜索、明确分类和主题结果不足 24 张时按实际数量显示；零结果是正常成功并清空列表，不用无关随机图片补齐。随机发现需要有界补齐，仍不足时说明情况；API 限流或响应异常保留上次成功列表及其实际图源、关键词和分类，不用旧结果冒充新筛选成功。

撤销 HTTPS 权限后，在途结果不会替换已经显示的列表；重新授权后，通过新的查询或刷新加载结果。图库预览处理繁忙时保留已有列表并提示重试，不把暂时繁忙标记为图片损坏。

请求经 HTTP effect / `host-result` 完成；插件验证图源、关键词 / 分类、轮次、effect ID、URL、状态与有界 JSON，再原子替换列表和成功筛选。会话 schema 3 只保存经验证的有界元数据，不保存图片二进制、系统路径或原生资源 ID；旧搜索会话与未来状态拒绝覆盖并保留原件。结果标识不代表下载资格。

图片卡片通过通用资源服务获取并重绘为安全 data URL，不直接加载远程 `img`。缩略图预览完成就释放原生资源，保持 24 张卡片不需要占用 24 个句柄。资源绑定当前安装和窗口，10 分钟过期；成功、失败、取消、卸载和切换后的晚到回调均清理句柄，不带入会话。

大图预览使用有界图片区域与固定操作栏；顶部信息图标打开独立图片信息窗口，查看图源、作者、许可、尺寸与来源地址时不改变主预览布局。信息窗口可独立滚动，关闭后回到信息入口；再次按 Esc 关闭预览并回到原图片卡片。

- **下载原图**：资源服务核验 MIME、真实解码与额度，再通过原生另存对话框保存已验证的原始文件；取消明确返回取消，不暴露系统路径。
- **加入图库**：把有效图片资源交给图库 `import-resource`；宿主重绘压缩并核验容量。界面按响应中的 `limit` 显示容量，无效或超额列表会被拒绝并保留已加载内容；压缩副本不作为原始文件另存。
- **应用背景**：选择图库图片及覆盖 / 完整显示方式，使用既有设置 revision CAS 保存并同步多窗口；冲突时刷新后重新选择。
- **本机管理**：本地图片通过用户选择导入；点击缩略图设为应用背景，右上角勾选表示当前使用项，名称旁的铅笔与垃圾桶图标直接重命名或移除。移除前确认；移除当前使用项后恢复纯色背景，不删除用户原始文件。其他窗口已经修改背景设置时，旧快照的移除操作会提示冲突并保留图片，刷新后再操作。

原图最多 16 MiB、每边 8192 像素、总计 1600 万像素。上游可能提供超过额度的高分辨率原图，此时预览仍可使用较小缩略图，下载与导入按宿主实际反馈处理。公网 URL、MIME、真实解码与额度最终由 [原生安全边界](../../docs/security.md#原生服务与外部来源) 核验；不跟随重定向或放宽 TLS。

## 网络连接

在宿主“设置 → 网络”中选择直接连接或跟随系统代理，默认跟随系统代理。壁纸库的图源 HTTP effect 与 `fetch-image` 均省略 `networkMode`，随请求继承宿主设置，不恢复旧检查点中的模式。直接连接禁止代理，宿主核验全部解析地址并固定到本次连接，拒绝私网、环回及保留网段。VPN Fake-IP 等合成保留地址可能因此被拒绝。

系统代理仍需要给壁纸库独立授予 `network:system-proxy`；宿主选择系统代理但插件未获授权时回落直连。代理沿用宿主支持的用户系统配置和排除规则，插件不能指定代理 URL、任意请求头、关闭 TLS 或绕过来源声明。命中系统代理时，宿主不能核验代理远端最终解析的目标 IP；没有匹配代理或被排除而直连时仍执行 DNS 检查。授权系统代理表示接受该信任边界，不承诺任意 PAC 支持；显式旧 `networkMode` 的兼容与权限规则见 [宿主扩展指南](https://github.com/YanChao001/tauri-desktop-starter/blob/develop/docs/extensions.md#来源与授权)。

## 开发与验证

从市场仓库根目录运行：

```sh
cargo test --locked --manifest-path plugins/wallpaper-browser/Cargo.toml --target-dir target/wallpaper-browser-native
cargo clippy --locked --manifest-path plugins/wallpaper-browser/Cargo.toml --target-dir target/wallpaper-browser-native --all-targets -- -D warnings
cargo build --locked --release --target wasm32-unknown-unknown --manifest-path plugins/wallpaper-browser/Cargo.toml --target-dir target/wallpaper-browser
node --test plugins/wallpaper-browser/ui/main.test.mjs
```

依赖 `serde`、`serde_json`、`url`，分别用于有界状态、JSON 响应解析和 URL 规范化；已移除不再需要的 HTML 正则解析依赖。这些依赖均为 MIT / Apache-2.0 许可的纯 Rust 依赖，支持本插件的原生测试和 Wasm 目标，不新增系统库或网络运行时。包体以实际构建产物为准，不预估未经测量的数字。

原生测试检查四图源解析、关键词编码与长度、真实分类 / 主题、固定图片身份、24 张去重、有界补齐、零 / 少量结果、失败保留筛选与 HTTPS 来源；手写 [`smoke.json`](./smoke.json) 检查真实 Wasm 图源 effect、回执和授权。按 [开发指南](../../docs/development.md) 准备工具后执行完整市场检查；资源、网络、图库 CAS、真实网站、WebView 与对话框的分层验收见 [测试规范](../../docs/testing.md#固定原生服务验收)。界面 DOM / SDK 替身不代表真实联网成功。

既有图库、背景偏好和设置保留；不以清空图库修复图源错误。会话文件绑定插件及 UI 文档版本，旧会话不能冒充新版状态，配套发布见 [发布指南](../../docs/publishing.md#固定配套宿主)。
