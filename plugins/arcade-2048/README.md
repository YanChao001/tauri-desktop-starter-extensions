# 数字合并

独立 Rust / Extism 插件，使用包格式 3、API 2 与视图版本 2。命令 `play` 可在侧栏或独立窗口打开，界面由本插件的 [ui/main.html](./ui/main.html) 自定义，在宿主隔离内容框中运行；规则与历史校验仍由 Wasm 完成。

先聚焦棋盘，用方向键、触屏滑动或四个方向按钮移动方块；相同数字每步只合并一次，合并结果计入分数。有效移动后生成一个 2 或 4；无效移动不改变随机序列。支持撤销、失利判断及合成 2048 后继续游玩。种子放在可展开的棋局设置中，输入整数种子后重新开局，相同种子和操作历史可重现整局。

不需要必需权限，也不请求网络、文本或文件能力。可选 `storage` 仅在点击“保存当前纪录”时发起真实宿主存储效果，使用当前 revision 检查并发冲突；不会自动重试或假装已经保存。棋盘保存在当前会话，长期保留棋盘可使用宿主的会话导出。撤销或新开局不降低已保存纪录。

状态只保存经过限制的种子及最多 4096 个有效方向操作；每次调用重放验证棋盘、分数与随机数序列，拒绝未知 schema、额外字段、无效种子、超长及不可达历史。游戏不会接受前端直接指定分数或方块。

从市场仓库根目录验证规则：

```sh
cargo test --manifest-path plugins/arcade-2048/Cargo.toml --locked --target-dir target/arcade-2048-native
```

市场统一构建流程会编译 Wasm 并通过宿主真实 worker 执行 [手写 smoke fixture](./smoke.json)。fixture 覆盖中英初始化、移动、撤销、存储请求、成功回执及冲突回执；宿主还会完整校验每份返回视图。玩法验证不启动桌面窗口。
