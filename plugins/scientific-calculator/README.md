# 科学计算器

离线科学计算、表达式历史、记忆寄存器和多函数绘图。业务计算由 Rust / Extism Wasm 执行；隔离 HTML 界面负责输入、Canvas 绘制和坐标交互，不使用 `eval`、动态函数或远程服务。

## 计算与图形

- 支持括号、`+ - * / % ^`、一元正负号、阶乘、科学计数、`pi` / `e` / `tau`、`ans` / `mem` / `x`，以及三角、反三角、对数、平方根等函数。幂右结合：`2^3^2 = 512`，`-2^2 = -4`。
- RAD / DEG 控制三角函数的输入与反三角函数的输出。`log` / `log10` 为常用对数，`ln` 为自然对数；`%` 表示带符号的余数，不是百分比。表达式需明确写乘号，如 `2*pi`。变量 `x` 用于曲线和数值分析，普通表达式计算时为 0。
- MS 保存上次答案，M+ 累加上次答案，MC 清空记忆；最近 32 条历史留在工作区，可生成 Markdown 记录并由用户选择位置保存。
- 每行一条函数，最多三条，使用变量 `x`。插件每次绘制每条曲线 641 个实际采样点；无定义或变化过大的采样段断开，不跨越明显渐近线画实线。界面支持拖动 / 方向键平移、滚轮 / 加减号缩放和适配 Y 轴；手势结束后重新采样，不逐像素调用 Wasm。
- 曲线及对应图例使用明暗主题下均可区分的蓝、橙、青三色，保留函数序号与名称；应用中性强调色不改变三条曲线的区分。“适配 Y 轴 / 重置坐标 / 绘制曲线”同排同高，窄屏文字换行时仍保持一致高度。
- 对所选函数在 `[a,b]` 中寻找一个根，或计算数值定积分。算法有计算和收敛限制；没有找到合法夹根或积分无法收敛时报告错误，不返回伪造结果。求根不是全根搜索，不保证偶重根可发现。

拖动、连续缩放与键盘平移先在本地绘制坐标预览。字段和会话检查点最多每 250 毫秒合并发送一批，正在发送时继续收集最新输入；停止操作后的绘图调用会先确认最后一份草稿再执行。输入字段始终覆盖当前值，不累积指针历史或图形截图。

绘图与数值分析均为有限精度近似；窄峰、未命中的奇点和采样间的细节可能不可见。不要把连线当作连续性证明，使用数学定义域和误差要求判断结果。每个表达式最多 4096 UTF-8 字节，最多三条函数的合计输入仍为 4096 字节，极端复杂表达式还受宿主资源预算限制。

## 工作区与权限

计算、绘图、历史、记忆和导出无需权限。可选 `storage` 仅用于用户主动保存或载入工作区；打开插件不会自动写入。会话导出 / 导入由宿主处理，未持久保存的工作区可以随会话保留。

保存通过宿主原子存储 effect 和 revision 比较完成，匹配成功回执后才显示保存确认。发生冲突或失败时保留当前工作区，不自动重试；先审阅另一窗口的修改再决定是否再次保存。载入会用保存的工作区替换当前会话，请先导出需要保留的计算记录。不兼容或损坏的保存内容拒绝覆盖并保留原件。

私有数据使用 `calculator-workspace` 键和 schema 1。用户可在扩展管理中撤销存储授权，仍可继续离线计算。本插件不请求网络、系统凭据、文本读取或直接文件系统访问。

## 开发验证

从市场根目录运行：

```sh
cargo test --locked --manifest-path plugins/scientific-calculator/Cargo.toml --target-dir target/scientific-calculator-native
cargo fmt --manifest-path plugins/scientific-calculator/Cargo.toml -- --check
cargo build --locked --release --target wasm32-unknown-unknown --manifest-path plugins/scientific-calculator/Cargo.toml --target-dir target/scientific-calculator
```

再通过市场 `check` 或对应的 `extension-tool test` 执行手写 `smoke.json`。数学内核的原生测试覆盖运算优先级、定义域、角度制、求根与积分；真实 Wasm smoke 检查双语视图、计算结果、产物和可选授权。离线 fixture 不代表真实桌面存储或 Canvas 交互已经验收。

协议与工具准备见[开发指南](../../docs/development.md)，界面、存储与桌面验收见[测试规范](../../docs/testing.md)。源码与本插件均采用仓库 MIT 许可证，无新增依赖。
