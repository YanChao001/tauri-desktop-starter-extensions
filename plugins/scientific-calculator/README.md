# 计算器

1.2.3 参照 Windows 11 计算器提供标准、科学、绘图、程序员和日期计算五种模式，以及货币、体积、长度、重量、温度、能量、面积、速度、时间、功率、数据、压强和角度十三类转换器。业务计算由 Rust / Extism Wasm 执行，隔离 HTML 界面负责按键输入、模式导航、Canvas 绘制和坐标交互，不使用 `eval` 或动态函数。五种计算模式与十二类单位换算均可离线使用；货币汇率通过可选的受控 HTTPS 请求更新。

Windows 风格的专用设计范围包括系统已安装的 Windows 字体族、内容配色，以及数学键盘、模式导航、数字 / 表达式显示、图表和无框的单位 / 日期模式入口。普通坐标与日期偏移输入、工作区按钮和确认弹层继续使用宿主统一注入的尺寸、圆角、材质及禁用 / 焦点规则；专用单位 `select` 保留无框布局，字号跟随宿主输入规则，选项文字沿用 SDK 的统一样式。其余通用界面按 [共同外观要求](../../docs/plugin-authoring.md#界面与宿主保持一致) 维护，“Windows 风格”不豁免无明确用途的重复 CSS。

左上角导航抽屉按“计算器 / 转换器”分组，底部“设置”中的工作区入口提供保存、载入和导出。默认使用标准模式；各模式和转换类别分别保留未完成的输入，切换后可以继续操作。新工作区的绘图模式显示空白方程与坐标轴，不预填示例曲线；已有工作区保存的函数正常恢复。独立窗口初始尺寸为 420 × 720，宿主已有的窗口位置与尺寸记录优先恢复。

当前包最低要求宿主 0.1.8，以使用新的共享界面规则；1.2.0 已依赖独立窗口控制服务与最多 32 个视图字段的协议额度。旧的同版本开发快照可能仍使用旧额度或缺少所需能力，仅刷新前端、替换插件包或修改版本号不能补齐原生实现。配套版本与固定源码要求见[发布指南](../../docs/publishing.md#固定配套宿主)。

## 标准模式

- 默认从标准模式的 `0` 开始，四列键盘保留独立的 `%`、CE 和 C。CE 清除当前输入，C 清除整条计算；`±` 改变当前输入正负号，退格处理完整字符。
- 四则运算按输入顺序执行，例如 `2 + 3 × 4 = 20`；科学模式的同一算式遵循运算优先级，结果为 `14`。
- 百分数保留上下文：`200 + 10% = 220`、`200 × 10% = 20`。支持倒数、平方、平方根和重复等号。
- 基础十进制四则计算使用有界的任意精度整数与有理数，过程中不转换为二进制浮点数，例如 `0.1 + 0.2 = 0.3`。非终止小数与非完全平方的平方根最多显示 32 位有效数字；复杂度、指数范围和状态额度仍有限制。

## 科学模式

- 默认采用 DEG。数字、运算符和括号可用屏幕键盘或实体键盘输入，支持粘贴表达式。科学模式遵循运算优先级，幂右结合：`2+3*4 = 14`、`2^3^2 = 512`、`-2^2 = -4`。
- `2nd` 切换平方 / 立方、平方根 / 立方根、幂 / 任意次根、`10ˣ` / `2ˣ`、常用对数 / 指定底数对数、自然对数 / `eˣ`。一元运算作用于当前输入，二元运算保留尚未完成的表达式。
- DEG / RAD / GRAD 控制三角函数的输入与反三角函数的输出；`F-E` 切换普通显示与科学计数显示。`exp` 输入十进制科学计数的指数，例如 `1 exp 3 = 1000`；`eˣ` 通过 `2nd` 使用。
- 三角学菜单提供 `sin`、`cos`、`tan`、`sec`、`csc`、`cot`，并通过菜单内的 `2nd` 和 `hyp` 切换反函数、双曲函数及反双曲函数。函数菜单提供绝对值、向下 / 向上取整、随机数，以及十进制度与度分秒数字的互换。
- `CE` 清除当前输入，`C` 清除整条计算，退格删除光标前的完整字符。`±` 改变当前输入的正负号，完成计算后输入数字开始下一条计算，输入运算符则继续使用当前答案。

常用快捷键：`Enter` / `=` 计算，`Backspace` 退格，`Delete` 清除当前输入，`Esc` 先关闭弹层、再清除计算，`F9` 切换正负号。`Alt+1` 到 `Alt+5` 依次进入标准、科学、程序员、日期和绘图模式，`Ctrl+E` 也可进入日期模式。菜单与按钮保留 Tab、Enter 和空格操作；编辑绘图字段时不会把普通文字输入当作计算器快捷键。

基础算术优先走十进制引擎，仅其不支持的科学语法或非整数幂交由有限精度 `f64` 近似计算；预算、范围与定义域错误不会绕过精确引擎的检查。三角函数、对数等仍可能出现舍入误差或范围限制，没有采用 Windows 计算器自身的数学引擎。负底数的非整数幂目前不支持，例如 `(-32)^0.2`；奇数次根可使用 `root(-32,5)` 得到 `-2`。

## 程序员模式

- 同时显示 HEX / DEC / OCT / BIN，默认 DEC 和 QWORD；字长可切换为 QWORD / DWORD / WORD / BYTE，即 64 / 32 / 16 / 8 位。
- 使用二补码整数计算，进制转换、位运算和位翻转不经过浮点数。超出字长的结果按该字长回绕，缩短字长保留低位。
- 提供 AND、OR、NOT、NAND、NOR、XOR，以及算术移位、逻辑移位、循环移位和带进位循环移位。根据当前进制禁用不适用的数字，程序员模式不接受小数。
- 位翻转视图按 63 到 0 显示 64 位，超出所选字长的高位禁用，点击可切换单个位。两种键盘共用固定输入区域，切换时保持上方数值、进制与工具栏的位置。此模式保留记忆，不显示标准 / 科学历史。

## 日期计算

- “日期之间的差值”显示年月周日差值及总天数；交换起止日期仍显示正差值。
- “添加或减去天数”从指定日期添加或减去年、月、日，三个偏移各为 0–999。年月运算遇到不存在的月末日期时，截断到目标月份的最后一天；日期计算不通过毫秒差换算，不受夏令时影响。
- 使用公历，支持 1601–9999 年。无效日期与越界结果报告错误，不自动替换用户输入。

## 转换器

十三类转换器按 Windows 计算器的顺序进入导航抽屉：货币、体积、长度、重量、温度、能量、面积、速度、时间、功率、数据、压强、角度。每类都以上下两组“数值 / 单位”显示。点击任一数值即可改为编辑该侧，活动数值加粗；随后输入数字会开始新的数值，正负号直接改变当前数值。两组单位保留原来的显示位置，单位变更后自动重算，不需要等号或交换按钮。

数字键盘为三列五行：第一行左侧留空、中间 CE、右侧退格，之后依次为 `7 8 9`、`4 5 6`、`1 2 3`、`± 0 .`。仅温度、功率和角度显示正负号，其余类别不接受负数。支持实体键盘和粘贴十进制数值；竖屏下键盘位于结果下方，窗口宽高比达到 1 时变为左侧结果、右侧键盘。

粘贴科学计数值后，数字、小数点或退格开始新的数值，正负号仍作用于整个已有数值。换算结果切换为输入时，必要时无损改用科学计数法；仍超出输入额度时保留原输入并提示，不截断有效数字。

离线单位目录固定取自 Microsoft 官方计算器提交 `79e1ac53bba690cdf930e5dcd6ed9dbc4cbfb128`，保留 158 个单位的标识、中文 / 英文名称、缩写与系数：131 个常规单位、1 个仅特定地区显示的坪（Pyeong），以及 26 个趣味比较单位。当前中英文界面共提供 131 个常规下拉项；坪保留在目录中，按地区条件过滤。趣味比较单位用于下方“约等于”，不加入普通单位下拉。补充区域按可用宽度显示，超出部分不展示。目录及许可证见 [converter-catalog.json](./src/converter-catalog.json) 和 [第三方归属与许可](./THIRD_PARTY_NOTICES.md)。

换算系数保留十进制文本，乘除由有理数引擎执行；温度通过摄氏、华氏、开尔文之间的仿射变换换算，`5/9` 保持为分数。数据类别区分十进制和二进制前缀。非终止小数按十进制引擎的显示额度舍入，单位目录中的上游近似常数仍保留其精度限制。

### 货币与汇率来源

货币使用 [ExchangeRate-API Open Access](https://www.exchangerate-api.com/docs/free) 的真实日更数据，固定请求 `GET https://open.er-api.com/v6/latest/USD`，再在本地计算所选币种的交叉汇率。初始列表包含 166 个公开货币代码；取得有效缓存后，支持项以实际响应为准。名称由当前语言的 `Intl.DisplayNames` 显示，不把预置代码列表当作已取得的汇率。

首次没有缓存时显示“更新汇率后即可换算”，不会用演示数字生成货币结果。进入货币类别后，若尚无缓存或已超过提供商给出的下一更新时间，且用户已授予 HTTPS 权限，当前界面会自动尝试更新一次；也可点击“更新汇率”主动重试。普通数值输入和币种切换使用当前缓存，不逐次联网。页面显示汇率等式及提供商返回的实际更新时间；每日更新是数据源的频率，不代表实时交易报价。更新失败、限流、无效响应或返回比已有缓存更旧的数据时保留旧缓存，并给出反馈。

成功响应保留在会话状态中；主动保存工作区时，汇率缓存会随工作区保存和恢复。未授予存储权限时仍可在当前会话使用已取得的缓存。缓存保留实际更新与下次更新时间，不把打开插件、恢复工作区或本地重算的时间冒充汇率更新时间。

货币页面保留“[Rates By Exchange Rate API](https://www.exchangerate-api.com)”署名与来源入口。开放端点允许个人或商业换算及终端用户缓存，要求署名，禁止将数据作为原始汇率服务再分发；汇率仅供信息与示例用途，不用于实际交易。使用来源须遵守其 [服务条款与隐私政策](https://www.exchangerate-api.com/terms)，本插件不提供面向第三方的原始汇率查询接口。

## 绘图与科学表达式

- 表达式支持括号、`+ - * / % ^`、一元正负号、阶乘、科学计数、`pi` / `e` / `tau`、`ans` / `mem` / `x`，以及三角、反三角、双曲、对数、平方根与任意次根等函数。
- `log` / `log10` 为常用对数，`ln` 为自然对数；`mod` / `%` 使用 Windows 科学模式的模运算，非零结果符号跟除数，例如 `-5 % 2 = 1`、`5 % -2 = -1`，不是百分比。粘贴或输入函数表达式时需明确写乘号，如 `2*pi`。变量 `x` 用于曲线和数值分析，普通表达式计算时为 0。
- 工作区最多保留最近 32 条历史，可生成 Markdown 记录并由用户选择位置保存。一元操作的预览不会逐次追加历史。历史中的连续空白合并为一个空格；会话状态达到 240,000 字节额度时仅移除最旧历史，保留当前输入、上次答案和记忆，并给出提示。
- 每行一条函数，最多八条，使用变量 `x`，例如 `sin(x)` 或 `y=sin(x)`。三条以内每条曲线使用 641 个实际采样点；更多曲线共享 1920 个采样区间预算，点数随曲线数调整。无定义或变化过大的采样段断开，不跨越明显渐近线画实线。界面支持拖动 / 方向键平移、滚轮 / 加减号缩放和适配 Y 轴；手势结束后重新采样，不逐像素调用 Wasm。
- 方程列表使用八种曲线颜色，每条保留 `fₙ` 序号、函数内容、显示 / 隐藏开关和线型切换。宽界面左侧显示图表、右侧显示方程列表与数学键盘；窄界面通过顶部按钮切换图表和输入面板。
- 对所选函数在 `[a,b]` 中寻找一个根，或计算数值定积分。算法有计算和收敛限制；没有找到合法夹根或积分无法收敛时报告错误，不返回伪造结果。求根不是全根搜索，不保证偶重根可发现。

拖动、缩放与平移先显示本地预览，字段和检查点每 250 毫秒合并最新草稿，停止后用最新视口重新计算，不累积指针历史或截图。

绘图与数值分析均为有限精度近似；窄峰、未命中的奇点和采样间的细节可能不可见。不要把连线当作连续性证明，使用数学定义域和误差要求判断结果。每个表达式最多 4096 UTF-8 字节，八条函数的合计输入仍为 4096 字节，极端复杂表达式还受宿主资源预算限制。

## 工作区与权限

计算、绘图、离线单位换算、历史、记忆和记录导出无需权限。权限均为可选，缺少货币联网或来源外链权限时仍可使用其余离线功能：

| 权限                   | 用途                                                                         |
| ---------------------- | ---------------------------------------------------------------------------- |
| `storage`              | 用户主动保存或载入工作区，包括已有的汇率缓存；打开插件不会自动写入私有存储。 |
| `window:control`       | 读取与切换调用插件自身独立窗口的置顶状态。                                   |
| `network:https`        | 仅向清单固定的 `https://open.er-api.com` 来源发送 GET 请求，更新汇率。       |
| `network:system-proxy` | 宿主网络设置使用系统代理时，允许汇率请求跟随该设置；未授权时按宿主规则直连。 |
| `links:open`           | 通过宿主受控来源外链服务打开 ExchangeRate-API 署名页面。                     |

网络连接方式继承宿主“设置 → 网络”，插件不配置代理地址，也不接收任意汇率 URL。会话导出 / 导入由宿主处理，未持久保存的工作区可以随会话保留。

MS 将当前显示值作为新条目存入记忆，最多 64 条，最新条目排在顶部；重复数值也能分别存入。顶部 M+ / M− / MR 操作最新条目，每条记忆还可单独取回、加减或删除，MC 清除全部记忆。未存入值时禁用清除和取回。标准与科学模式使用各自的历史，宽界面显示右侧历史 / 记忆面板，窄界面通过按钮展开；程序员模式仅显示记忆。

历史和记忆列表在各自区域内滚动，不随条目数量撑高左侧键盘；右下角清空按钮固定保留，按当前页签分别清空历史或记忆。计算期间会临时锁定操作，保持文字、背景和透明度，实际不可用的控件继续灰显。

保存通过宿主原子存储 effect 和 revision 比较完成，回执的 effect ID、递增 revision 和保存内容都匹配后才显示保存确认。发生冲突或失败时保留当前工作区，不自动重试；先审阅另一窗口的修改再决定是否再次保存。revision 耗尽时拒绝生成写入请求，保留原始存档。载入会用保存的工作区替换当前会话，请先导出需要保留的计算记录。不兼容或损坏的保存内容拒绝覆盖并保留原件。

私有数据使用 `calculator-workspace` 键和 schema 1。用户可在扩展管理中撤销可选授权，仍可继续离线计算与单位换算；已有汇率缓存仍可用于本地换算。本插件不请求系统凭据、文本读取或直接文件系统访问。

## 开发验证

从市场根目录运行：

```sh
cargo test --locked --manifest-path plugins/scientific-calculator/Cargo.toml --target-dir target/scientific-calculator-native
cargo fmt --manifest-path plugins/scientific-calculator/Cargo.toml -- --check
cargo clippy --locked --manifest-path plugins/scientific-calculator/Cargo.toml --target-dir target/scientific-calculator-native --all-targets -- -D warnings
cargo build --locked --release --target wasm32-unknown-unknown --manifest-path plugins/scientific-calculator/Cargo.toml --target-dir target/scientific-calculator
```

再通过市场 `check` 或 [单插件验收](../../docs/testing.md#聚焦单个插件) 执行手写 [`smoke.json`](./smoke.json)。原生测试检查数学、单位目录、换算边界、汇率响应与存储回执，真实 Wasm 检查双语视图、结果、产物和授权；界面回归运行 `node --test plugins/scientific-calculator/ui/main.test.mjs`。离线 HTTP 回执 fixture 不能代替真实网络连通性，浏览器 fixture 也不能代替独立原生窗口置顶、桌面存储或正式安装版验收。

协议与工具准备见 [开发指南](../../docs/development.md)，验证边界见 [测试规范](../../docs/testing.md)，依赖及许可见 [`Cargo.toml`](./Cargo.toml)、[第三方归属与许可](./THIRD_PARTY_NOTICES.md) 和仓库 [MIT 许可证](../../LICENSE)。

十进制引擎使用 Rust Num 的 `num-bigint`、`num-rational` 与 `num-traits`，分别提供整数、有理数及数值转换支持，版本由 Cargo 清单与锁文件维护。它们采用 MIT / Apache-2.0 双重许可，均为纯 Rust，不引入系统库、运行时网络请求或新权限，支持原生与 Wasm 构建；数值组件和计算预算由插件限制。UI 仍为自包含 HTML / CSS / JavaScript，没有新增前端框架或 npm 依赖。

界面与操作参照 Microsoft 官方的 [标准键盘](https://github.com/microsoft/calculator/blob/main/src/Calculator/Views/CalculatorStandardOperators.xaml)、[科学键盘](https://github.com/microsoft/calculator/blob/main/src/Calculator/Views/CalculatorScientificOperators.xaml)、[图形模式](https://github.com/microsoft/calculator/blob/main/src/Calculator/Views/GraphingCalculator/GraphingCalculator.xaml)、[程序员键盘](https://github.com/microsoft/calculator/blob/main/src/Calculator/Views/CalculatorProgrammerRadixOperators.xaml)、[日期计算](https://github.com/microsoft/calculator/blob/main/src/Calculator/Views/DateCalculator.xaml)、[转换器](https://github.com/microsoft/calculator/blob/main/src/Calculator/Views/UnitConverter.xaml) 与 [官方交互验收](https://github.com/microsoft/calculator/blob/main/docs/ManualTests.md)。未复制 Microsoft 的位图、安装图标或字体文件；界面使用 CSS、SVG 和当前系统已安装的字体。
