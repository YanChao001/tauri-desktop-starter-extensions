连接与隐私说明

把监听 IP 与端口告诉对方，双方均需先开启监听。仅接受数字形式的私有或回环 IP，不扫描网络。连接失败时核对同一网络、端口和系统防火墙；应用不会修改防火墙。

局域网 TCP 为明文传输，昵称由对方自行声明，未认证身份。仅连接可信设备，勿发送密码或敏感信息。本插件只收发文本，不访问或传输文件。

联系人来自真实连接，离线会话与最近最多 500 条消息 / 1 MiB 保存在本机。切换页面仍会收信；最后使用的应用窗口关闭、撤权或退出会停止连接。

“已写入连接”不等于对方收到；“已送达”表示对方已保存消息。
